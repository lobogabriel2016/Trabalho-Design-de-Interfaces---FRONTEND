FASE 1 — CONSTRUÇÃO DA TELA (ambiente local)
--------------------------------------------------------------------

1. ARQUIVOS QUE CRIEI (do zero)

1.1 src/app/pages/marca/marca-cadastro/marca-cadastro.component.ts
    - Componente STANDALONE de cadastro com Reactive Forms
    - Validators: nome (obrigatório, mín. 2, máx. 120 caracteres) e
      cnpj (obrigatório, 14 dígitos numéricos)
    - Trim dos valores antes do envio (regra 5.4 da documentação)
    - Chamada ao service para POST /api/marcas
    - Toast de sucesso/erro via MessageService (PrimeNG)
    - Botão travado enquanto envia; formulário reiniciado após salvar

1.2 src/app/pages/marca/marca-cadastro/marca-cadastro.component.html
    - Formulário com grid Bootstrap (container/row/col)
    - Inputs do PrimeNG (pInputText, pButton)
    - Mensagens de erro POR CAMPO (só quando tocado/inválido)
    - Envio bloqueado com [disabled]="form.invalid || enviando"

1.3 src/app/core/services/marca.service.ts
    - Service de comunicação com o backend — único lugar com
      HttpClient (regra 5.4)
    - inserir() -> POST /api/marcas
    - listar()  -> GET /api/marcas?filtro=  (top 10 alfabético)
    - URL base vinda do environment

1.4 src/environments/environment.development.ts
    - apiUrl: 'http://localhost:8080/api' para o modo dev (contrato
      da seção 6.1)

2. ARQUIVOS QUE MODIFIQUEI NA MINHA VERSÃO

2.1 src/app/app.routes.ts — rota de cadastro + redirect da raiz
2.2 src/app/app.html — substituição do placeholder por
    <router-outlet /> para as rotas renderizarem
2.3 src/styles.css — imports do Bootstrap e PrimeIcons
2.4 package.json — dependência de temas do PrimeNG

OBSERVAÇÃO DE BOA PRÁTICA: o arquivo core/models/marca.model.ts já

3. PROBLEMAS TÉCNICOS DIAGNOSTICADOS E RESOLVIDOS

1) NG2008 — stylesheet do componente ausente -> arquivo recriado
2) TS2339 — 'apiUrl' sem tipagem no environment de dev -> corrigido
3) NG0201 — 'No provider found for MessageService' -> providers
   adicionados no componente
4) Botão sem rótulo — API do PrimeNG 22 não aceita mais 'label' no

6) Formulário sem estilos — Bootstrap/PrimeNG não eram carregados no
   build (styles.css vazio) -> CSS global + tema configurados
